| מסך הפתיחה באנדרואיד, ברגע שהאפליקציה נפתחת | האייקון במרכז, על הרקע של האפליקציה |
| הלשונית בדפדפן | האייקון בגודל זעיר, 16 עד 32 פיקסלים |

## הבריף למעצב

1. **הצבעים:** מהפלטה של האפליקציה, בלבד.

   | הצבע | הקוד | השימוש באפליקציה |
   | :-- | :-- | :-- |
   | סגול ראשי | `#6a45f5` | כפתורים, הלשונית הפעילה, הטבעות |
   | סגול בהיר | `#eeeafe` | רקעים רכים |
   | סגול-שחור | `#1a1830` | טקסט |
   | רקע האפליקציה | `#f3f3f8` | רקע המסכים |

2. **הסגנון:** נקי ושטוח, כמו האייקונים שבתוך האפליקציה: קווים מעוגלים, בלי צללים כבדים ובלי טקסט. מעבר צבע עדין מותר.
3. **הסמל:** צורה אחת פשוטה שנקראת גם בגודל 32 פיקסלים. האייקון הנוכחי הוא משקולת. אפשר להישאר איתה, או להציע סמל אחר שמעביר כושר ומעקב.
4. **בלי טקסט ובלי אותיות.** בגודל של מסך הבית הן לא נקראות.
5. **הדוגמאות שהוצגו:** שלוש אפשרויות למשקולת סגולה הוצגו בשיחה עם Claude (A: סגול מלא, B: מעבר צבע, C: סגול בהיר). אפשר להשתמש בהן כנקודת פתיחה, או לא להשתמש בהן בכלל.

## הקבצים למסירה

**הדרך הפשוטה: קובץ אחד.**

| הקובץ | הגודל |
| :-- | :-- |
| `אייקון-אפליקציה-1024.png` | 1024 × 1024 |

**או, אם המעצב מעדיף לייצא כל גודל בעצמו**, למשל כדי לפשט את הסמל בגודל הזעיר:

| הקובץ | הגודל | איפה הוא משמש |
| :-- | :-- | :-- |
| `icon-512.png` | 512 × 512 | אנדרואיד, ומסך הפתיחה |

| `apple-touch-icon.png` | 180 × 180 | אייפון, במסך הבית |
| `favicon-32.png` | 32 × 32 | לשונית הדפדפן |

**לאן שומרים:** לתיקייה `תמונות וגרפיקה`, ליד האיורים.

## רשימת בדיקה לפני המסירה

- [ ] הסמל נקרא בבירור גם כשמקטינים אותו ל-32 פיקסלים.
- [ ] הסמל כולו בתוך 80% האמצעיים של הריבוע.
- [ ] אין שקיפות, ואין פינות מעוגלות בקובץ.
- [ ] אין טקסט או אותיות.
- [ ] הצבעים מהפלטה שלמעלה.
- [ ] הקובץ, או ארבעת הקבצים, בשמות המדויקים, בתיקייה `תמונות וגרפיקה`.

## מה קורה בסוף התהליך

**כותבים ל-Claude:** "האייקון מוכן".

**מה Claude עושה עם הקובץ:**

1. בודק אותו מול רשימת הבדיקה, ומראה איך הוא נראה בגודל של מסך הבית ובגודל של לשונית הדפדפן.
2. מכין את ארבעת הגדלים, אם התקבל קובץ אחד, ומחליף את הקבצים הקיימים בתיקייה `app/public`, באותם שמות. המניפסט והקוד לא משתנים.
3. בודק בדפדפן שהאייקון מופיע בלשונית ובמניפסט.
4. שומר את השינוי בענף `design-refresh-v4`, ומבקש את **אישור הצוות**.
5. בבדיקה בטלפון במשימה 5: מוסיפים את האפליקציה למסך הבית, ובודקים את האייקון שם.

**לידיעה:** טלפון שכבר הוסיף את האפליקציה למסך הבית יכול להמשיך להציג את האייקון הישן לזמן מה. מחיקה והוספה מחדש מעדכנות אותו מיד.
