## ההחלטה המבנית של השלב

הלקוח (client.ts) מנתב לפי הפונה: המסך S04 עובר למתאם האמיתי, שפונה ל-Endpoint; כל שאר המסכים נשארים על מתאם ההדגמה. בכל שלב בהמשך מתווספים מסכים לרשימה, ואף מסך אינו משתנה. נתוני ההדגמה במסד ובמתאם ההדגמה נושאים **אותם מזהים** (UUID קבועים), כדי שמעבר מ-S03 (הדגמה) ל-S04 (אמיתי) יעבוד על אותו מתאמן.
