## מה נבדק ונמצא תקין

- RLS פעיל בכל 26 הטבלאות, בלי מדיניות לציבור; המפתח הציבורי אינו קורא טבלאות ואינו מריץ את פונקציות המסד (נבדק במבחנים).
- כל פעולה שמקבלת מזהה מהמסך בודקת שייכות (חוק 5): מתאמן רק את שלו, מאמן רק את המתאמנים שלו. save_program מוגבל בפונקציית המסד לתוכנית עצמה.
- אין שרשור ערכים מהמסך למסננים של המסד: המסננים הבנויים משתמשים רק במזהים מהמסד או במזהים שעברו בדיקת UUID.
- אסימון ההזמנה אקראי (192 סיביות), חד פעמי ובתוקף מוגבל; ההצטרפות אטומית.
- מצטרף שלא הצטרף אינו מגיע לשום נתון.
- אין מפתחות במאגר (מבחן 9.8). מפתח השירות רק בפונקציה.
- הודעות השגיאה הן קודים מהרשימה הסגורה, בלי פרטי מסד.
- העלאה: רק וידאו, עד 50 מגה-בייט, ורק לנתיב שהשרת בחר.
- אין פרטי כרטיס (חוק 12).
