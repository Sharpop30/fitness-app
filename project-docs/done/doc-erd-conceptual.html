ההחלטות שבמודל

  • היתרה, השיא והרצף אינם נשמרים. הם מחושבים בכל פעם מיומן המטבעות ומהתוצאות, כפי שאושר במקרי השימוש 5, 7 ו-9.
  • אין פרטי כרטיס אשראי בשום טבלה.
  • פרטי הכניסה (מייל וסיסמה) נשמרים בשירות הזהות של Supabase, ו-COACHES ו-TRAINEES מפנים אליו.
  • ארבע הטבלאות התפעוליות משתנות בלי שום שינוי במסך. זה המצב התקין, לפי מתודולוגיית הכוכב, פרק ג.
