## 1. המקור

- הסיפור: story-01-training-programs, דרישה 1, ניהול תוכניות אימון.
- **SO THAT**: המאמן מתאים את האימון לכל מתאמן במהירות ובמקום אחד, והמתאמן מתאמן תמיד לפי התוכנית העדכנית. זה מבחן הרלוונטיות של כל צעד.

- **פתיחה**: המאמן מחובר, והמתאמן מחובר אליו (הצטרף בהזמנה, סיפור 19).
