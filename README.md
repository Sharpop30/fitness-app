# fitness-app: אפליקציית ניהול מאמן כושר

אפליקציה למאמן כושר אישי ולמתאמנים שלו: תוכניות אימון, תשלומים וחשבוניות, ומעקב אחרי תוצאות. הפרויקט נבנה לפי מתודולוגיית הקורס "מיישמי AI בארגונים", ומסד הנתונים הוא Supabase.

## איפה מה

| התיקייה | מה יש בה |
| :-- | :-- |
| `project-docs/` | המסמכים המאושרים: ה-PRD, הדרישות, סיפורי המשתמש ועוד. מקור האמת של מבנה הקבצים: `project-docs/file-system-index.md` |
| `drafts/` | טיוטות שממתינות לאישור |
| `archive/` | קבצים שהוחלפו |
| `automation-infra/` | רישום הריצה של עדכון ה-PRD |
| `reference/form/` | קוד ואב טיפוס של פרויקט קודם (FORM), כמקור השראה בלבד |

## מצב הפרויקט

בשלב הקליטה והשלמת האבחון והאפיון. הבנייה מתחילה אחרי שמפת המודולים ומסמך הבנייה מאושרים.
